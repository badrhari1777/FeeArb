## Как работает старт без позиции

1. На странице Grid создается стратегия для символа и пары бирж.
2. До первой сделки она отображается на Dashboard как `waiting first entry`.
3. Это планируемая стратегия, а не фиктивная биржевая позиция.
4. Когда исполнимый entry spread достигает первой ступени нужное число раз,
   Grid запускает один `smart-enter` чанк.
5. Реальный уровень меняется с `0` на `1` только после завершения операции и
   сверки long/short позиций с биржами.
6. Если фактический объем или баланс ног не совпал с целевым, Grid ставится на
   паузу и не отправляет следующий чанк.

## Таблица до запуска

Нажмите `Рассчитать таблицу + Dry Run`. Для каждой ступени выводятся:

- условие входа по исполнимому entry spread;
- операции `BUY` long-биржи и `SELL` short-биржи;
- условие обратного выхода;
- операции `SELL` long-биржи и `BUY` short-биржи;
- количество монет в чанке;
- оценочный номинал чанка в USDT на одну ногу;
- накопленный объем и номинал позиции;
- текущий статус условия входа.

Расчет является планом. Реальная цена исполнения может отличаться в пределах
разрешенного slippage.

## Безопасный первый Live-тест

1. Задайте бюджет так, чтобы таблица показывала:
   - не более `50 USDT` на один чанк на одну ногу;
   - не более `100 USDT` общей позиции на одну ногу.
2. Нажмите `Запустить Shadow`.
3. Проверьте таблицу, направление long/short и текущие спреды.
4. Нажмите `Включить Live`.
5. Введите точное подтверждение, которое покажет интерфейс:

```text
LIVE <id стратегии>
```

6. После включения стратегия будет ждать триггер. Нажатие кнопки само по себе
   немедленно не открывает позицию, если условие первой ступени не достигнуто.

## Ограничения первой Live-версии

- одновременно активна только одна Live Grid-стратегия;
- за один цикл исполняется только одна ступень;
- используется только существующий `smart-enter` / `smart-exit`;
- market fallback выключен;
- при другой ручной или автоматической операции Grid ждет;
- обычный Auto Exit для той же пары должен быть выключен;
- после ошибки, частичного результата или несовпадения позиций Grid
  автоматически ставится на паузу;
- изменение диапазона действующей Live-сетки пока запрещено;
- переход `В Shadow` не закрывает существующую реальную позицию.

## Важно

Live Grid размещает реальные заявки на обеих биржах. Перед включением проверьте
API-ключи, баланс, isolated margin, плечо 3x, направление ног и минимальный
размер ордера каждой биржи.
