# Автоарбитраж: Shadow-режим

Страница:

```text
https://app.feearb.ru/auto-arbitrage
```

Резервный адрес через Tailscale:

```text
https://desktop-0tl9bsa.tail3830e2.ts.net:8443/auto-arbitrage
```

## Что делает текущая версия

- Получает реальные стаканы long- и short-бирж.
- Рассчитывает исполнимый спред входа и выхода.
- Запускает Dry Run входа и выхода.
- Предлагает безопасный размер чанка и количество уровней.
- Виртуально набирает и закрывает уровни сетки.
- Сохраняет стратегии после перезапуска backend.
- Не размещает реальные заявки.

Текущая версия работает только в `Shadow`.

## Создание стратегии

1. Откройте `Auto arbitrage` на Dashboard.
2. Укажите монету, например `BTCUSDT`.
3. Выберите биржу для long и биржу для short.
4. Выберите бюджет в монетах или USDT.
5. Укажите первый и последний спред входа.
6. Оставьте `Уровней` и `Exit gap` пустыми для автоподбора.
7. Нажмите `Dry Run + автоподбор`.
8. Проверьте таблицу уровней и предупреждения.
9. Нажмите `Запустить Shadow`.

Пример диапазона:

```text
Первый вход:   -2%
Последний вход: -10%
```

При движении спреда вниз Shadow будет виртуально добавлять чанки. При обратном
движении уровни будут виртуально закрываться.

## Защита от ложных срабатываний

- Требуются два последовательных подтверждения уровня по умолчанию.
- За один цикл меняется максимум один уровень.
- Вход и выход рассчитываются по разным сторонам стакана.
- Exit gap не дает сетке постоянно переключаться на рыночном шуме.

## Управление

- `Пауза` временно прекращает обработку стратегии.
- `Продолжить` возобновляет ее.
- `Удалить` удаляет правило и его текущее Shadow-состояние.

История переходов сохраняется в:

```text
logs/auto_arb_history.jsonl
```

Правила сохраняются в:

```text
state/auto_arb_rules.json
```

## Важно

В режиме `Shadow` реальные позиции не открываются и не закрываются. Переход в
Live выполняется только отдельной кнопкой и текстовым подтверждением.
