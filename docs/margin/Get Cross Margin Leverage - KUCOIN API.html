Get Cross Margin Leverage

GET
https://api-futures.kucoin.com/api/v2/getCrossUserLeverage
api-channel:Private
api-permission:General
api-rate-limit-pool:Futures
sdk-service:Futures
sdk-sub-service:Positions
sdk-method-name:getCrossMarginLeverage
api-rate-limit-weight:2
Description
This interface can query the current symbol’s cross-margin leverage multiple.

Request

Query Params
symbol
string 
required
Symbol of the contract, Please refer to Get Symbol endpoint: symbol
Example:
XBTUSDTM

Request Request Example

Python
import http.client

conn = http.client.HTTPSConnection("api-futures.kucoin.com")
payload = ''
headers = {}
conn.request("GET", "/api/v2/getCrossUserLeverage?symbol=XBTUSDTM", payload, headers)
res = conn.getresponse()
data = res.read()
print(data.decode("utf-8"))
